# 代码模板抽卡默写

访问 `/code_template/`，从模板库把想练的模板加入个人卡组，再打开「我的卡组」。页面会先安排到期复习，再安排新卡，每天默认最多开始 5 张新卡，可以在设置中修改为 0–100 张。

抽到卡后，在空白编辑区默写。点击「查看答案」后，当前默写锁定，与参考代码并排展示，窄屏改为上下排列。完成对照后自行评价；系统不运行用户代码。

## 任务说明

在 `book/code.yaml` 的模板条目中添加可选字符串字段 `recall_prompt`：

```yaml
codes:
  - id: example
    path: example.cpp
    description: 示例模板
    recall_prompt: |
      在这里说明学生需要独立实现的功能。
      写清接口、编号范围及必要约定，不直接给出实现。
```

这是配置格式示例，路径需对应实际模板。任务说明以纯文本显示，保留换行。没有说明的模板同样可以加入卡组，卡片正面仅显示名称。列表和详情 API 均返回 `recall_prompt`，缺省为空字符串。预检查拒绝非字符串值。

## 复习安排

- 熟练写出：从 1 天开始，依次提升为 3、7、14、30 天，之后保持 30 天。
- 勉强写出：次日再练，保留当前间隔档位。
- 没写出来：档位回到起点，至少 1 分钟后可再次抽取，重新从空白默写。还有其他到期卡时可先练其他卡；等待重练期间不引入新卡。

到期卡之间、新卡之间随机抽取。每日新卡数在首次抽到时计入；刷新、重练和移除卡片不会返还当天额度。日期使用浏览器本地日历日期，跨月、跨年和夏令时按日历天计算。新卡上限设为 0 时仍可复习。未完成的卡片和草稿保存在本地，刷新后继续。

## 数据与备份

使用当前站点来源下的 `localStorage`，键名为 `rbook.code-recall.v1`。同一浏览器配置、同一站点来源共享一个个人卡组；不同学生使用各自浏览器配置，或用各自备份切换。清除站点数据会清除进度；跨设备或更换站点地址需手动导出、导入。

备份包含格式标识、版本、每日新卡上限、当天已开始的新卡数量、卡片 ID 与调度状态，以及当前默写草稿和是否已揭晓答案。导入先验证，用户确认后替换现有记录。无法匹配当前模板库的 ID 仍保留在卡组中，并标记暂不可用，不参与抽取。

存储失败会明确提示，不把未保存的评分当作完成。损坏的本地记录不会自动覆盖，可先导出原始数据，再导入有效备份恢复。暂不保存历次默写代码；自评后清空本次草稿。

## 验证

```sh
npm run test:code-recall
```

包括调度、日历边界、备份校验、API 字段传递，以及 Chromium 中的完整交互、刷新恢复、导入导出、窄屏布局与故障恢复。浏览器测试需已安装 Playwright Chromium。
