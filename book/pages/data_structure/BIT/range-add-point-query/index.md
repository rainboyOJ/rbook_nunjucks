## 前置回顾

本篇只组合两个已经学过的结论：

1. [基础树状数组](../index.md)支持差分数组的单点修改和前缀查询；
2. [差分](../../../base/differential/index.md)满足
   $$
   d_i=a_i-a_{i-1},\qquad a_i=\sum_{j=1}^{i}d_j
   $$

不再重复推导 `lowbit` 和普通差分，只关注两者怎样组合成在线算法。

## 一句话算法

把区间加法记在差分数组的两个边界上，再用树状数组求差分前缀和恢复单点值。

## 问题模型

给定长度为 $n$ 的数组 $a$，支持：

1. 区间修改：给 $a_l,a_{l+1},\ldots,a_r$ 都加上 `value`；
2. 单点查询：询问当前的 $a_x$。

如果每次区间修改都逐项更新，最坏需要 $O(n)$。普通差分虽然能 $O(1)$ 记录修改，但通常要等所有修改结束后再统一还原，不能高效处理修改与查询交替出现的情况。

## 核心转化

令：

$$
d_i=a_i-a_{i-1},\qquad a_0=0
$$

给区间 $[l,r]$ 中每个数增加 $v$，只会改变差分数组的两个边界：

$$
d_l\mathrel{+}=v,\qquad d_{r+1}\mathrel{-}=v
$$

![](../images/BITn4.png)

任意位置 $x$ 的值等于差分前缀和：

$$
a_x=d_1+d_2+\cdots+d_x
$$

![](../images/BITn6.png)

因此，问题变成基础树状数组最擅长的模型：

```text
原问题：区间修改 + 单点查询
             |
             v
差分数组：两个单点修改 + 一次前缀查询
```

## 算法步骤

### 初始化

读入原数组时计算相邻差：

```cpp
previous = 0;
for (int i = 1; i <= n; ++i) {
    cin >> value;
    bit.add(i, value - previous);
    previous = value;
}
```

树状数组实际维护的是 $d$，不是原数组 $a$。

### 区间修改

对 $[l,r]$ 增加 $v$：

```cpp
add(l, v);
if (r < n) add(r + 1, -v);
```

`d[l] += v` 表示影响从 $l$ 开始，`d[r+1] -= v` 表示影响在 $r$ 之后停止。

### 单点查询

查询 $a_x$：

```cpp
point_query(x) = prefix_sum(x);
```

例如原数组为 $[1,2,3,4,5]$，给 $[2,4]$ 加 $10$：

```text
原差分：  1  1  1  1  1
边界修改：   +10      -10
新差分：  1 11  1  1 -9
前缀还原：1 12 13 14  5
```

查询位置 $3$ 时，差分前缀和为 $1+11+1=13$。

## 算法证明

**核心不变量**：树状数组始终维护当前数组的差分 $d$，且

$$
a_x=\sum_{i=1}^{x}d_i
$$

区间 $[l,r]$ 增加 $v$ 后：

- $d_l$ 增加 $v$，所以从 $l$ 开始的前缀和都多出 $v$；
- $d_{r+1}$ 减少 $v$，所以从 $r+1$ 开始抵消这次增加；
- 因而只有 $a_l,\ldots,a_r$ 增加 $v$。

树状数组正确完成两个差分点修改，并正确返回差分前缀和，所以每次单点查询得到当前真实的 $a_x$。

## 复杂度分析

- 初始化：$O(n\log n)$；
- 区间修改：两次单点修改，$O(\log n)$；
- 单点查询：一次前缀查询，$O(\log n)$；
- 空间复杂度：$O(n)$。

## 易错点

1. 树状数组维护的是差分数组，`point_query(x)` 才是原数组的 $a_x$。
2. 只有当 `r < n` 时，`r+1` 才是有效差分下标。
3. 初始化时要加入 `a[i] - a[i-1]`，不能直接加入 `a[i]`。
4. 区间修改的右边界必须写成 `-value`，用于停止影响。
