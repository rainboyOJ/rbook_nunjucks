## 一句话算法

区间修改线段树把整段修改先记在大区间节点上，等以后必须访问孩子时再把标记下传。

## 问题模型

给定长度为 $n$ 的数组，支持两类操作：

1. 区间赋值：把 `a[l..r]` 全部改成 `x`。
2. 区间查询：求 `a[l] + ... + a[r]`。

如果区间赋值时逐个修改元素，一次操作最坏是 $O(n)$。懒标记线段树可以把区间修改和区间查询都做到 $O(\log n)$。

## 核心直觉

线段树查询时，如果一个节点区间完全被目标区间覆盖，可以直接使用这个节点的答案。

区间修改也一样：如果当前节点区间完全被修改区间覆盖，就没有必要继续递归到每个叶子。

我们只需要：

1. 直接更新当前节点的区间和；
2. 给当前节点打一个“整段已经被赋值为 x”的标记；
3. 等以后查询或修改需要进入孩子时，再把这个标记传下去。

这个标记就叫懒标记。

## 懒标记表示什么

对区间赋值来说，懒标记需要记录两件事：

- `tag[p]`：当前节点是否有尚未下传的赋值标记；
- `lazy[p]`：如果有标记，这个区间要被赋成什么值。

当节点 `[l,r]` 被整体赋值为 `x` 时：

```cpp
tr[p] = x * (r - l + 1);  // 区间和直接按长度算出来
lazy[p] = x;
tag[p] = true;
```

注意：区间赋值不是区间加法。新的赋值会覆盖旧的赋值标记；加法标记则是会累加的（见后面的区间加模板）。

## 算法步骤

### 区间赋值

1. 当前节点区间为 `[l,r]`。
2. 如果 `[l,r]` 完全包含在 `[L,R]` 中：
   - 更新 `tr[p]`；
   - 记录懒标记 `lazy[p]` 并置 `tag[p] = true`；
   - 返回。
3. 否则先 `pushdown(p)`，把旧标记下传给孩子。
4. 递归修改与 `[L,R]` 相交的孩子。
5. 回溯时重新合并当前节点。

### 区间查询

1. 如果当前节点区间完全在查询区间内，直接返回 `tr[p]`。
2. 否则先 `pushdown(p)`，保证孩子信息正确。
3. 递归查询相交的孩子。
4. 合并答案。

## 算法证明

**核心不变量**：`tr[p]` 始终表示节点 `p` 对应区间的真实区间和；若 `tag[p]` 为真，则它的孩子可能还没更新，但整个节点区间已经被统一赋值为 `lazy[p]`。

当一个节点被完整覆盖时，直接设置 `tr[p] = value * (r - l + 1)`，当前节点答案正确；记录懒标记表示孩子以后需要同步。

当后续操作必须访问孩子时，`pushdown` 会把赋值标记应用到两个孩子，使孩子的 `tr[p]` 与 `lazy[p]` 都正确。然后继续递归，回溯时重新合并父节点。

因此每次操作结束后，不变量仍成立，查询得到的区间和正确。

## 复杂度分析

设数组长度为 $n$。

- 建树：$O(n)$。
- 区间赋值：$O(\log n)$。
- 区间查询：$O(\log n)$。
- 空间复杂度：$O(n)$。

### 换成加法标记

区间加模板的输入输出与上面一致，只把 `op = 1 l r x` 的含义改成“把 `[l,r]` 每个数都加上 `x`”。改动集中在三处：

- `apply`：`tr[p] = (tr[p] + value * len) % mod`，`lazy[p] = (lazy[p] + value) % mod`（赋值是覆盖，加法是累加）；
- `pushdown`：判据从 `tag[p]` 换成 `lazy[p] != 0`，下推后 `lazy[p] = 0`；
- 建树与上推：每个加法都套一层 `% mod`，建树时叶子要 `norm(base[l])` 把负初值归一。

## 测试用例

输入：

```text
5 5
1 2 3 4 5
2 1 5
1 2 4 10
2 1 5
1 3 5 1
2 2 5
```

输出：

```text
15
36
13
```

这组数据没有负数，也不会触碰取模，所以区间赋值与区间加两个模板得到相同的 3 个数。区间加模板自己的取模与负增量行为需要单独验，直接拿模板文件（默认 `mod` 取 `1000000007`）跑下面这组：

```text
3 5
-5 0 7
2 1 3
1 1 2 -3
2 1 2
2 1 3
1 2 2 100
```

输出为：

```text
2
999999996
1000000003
```

初始和是 `-5 + 0 + 7 = 2`；`1 1 2 -3` 让前两个位置各减 `3`，此时区间 `[1,2]` 的真实和是 `-11`，取模后输出 `999999996`；整段和变成 `-4`，取模后输出 `1000000003`。最后一条命令只做修改、不输出，用来验证取模后后续操作仍然正确。

## 应用分类详解

区间修改线段树的本质是“整段操作先压缩记录，必要时再展开”。只要修改目标是一整段，且查询也是区间信息，就应该考虑懒标记。

### 一、区间赋值，区间求和

**典型模式：** 把一段全部改成同一个值，再查询区间和。

**识别信号：** 出现“区间覆盖”“区间染色”“整段改为 x”。

**核心建模：** 懒标记记录这段被赋成的值，节点和为 `x * len`。

### 二、区间加法，区间求和

**典型模式：** 给一段每个数都加上 `x`。

**识别信号：** 出现“区间加”“区间增加”“区间平移”。

**核心建模：** 懒标记记录待加值，节点和增加 `x * len`。

### 三、区间染色与覆盖统计

**典型模式：** 多次把区间染成某种颜色，最后统计颜色或覆盖长度。

**识别信号：** 出现“覆盖”“染色”“后来的操作覆盖前面的操作”。

**核心建模：** 区间赋值标记天然表示覆盖关系。
